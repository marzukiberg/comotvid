IG Story Saver

Download foto & video dari story Instagram privat
(akun yang kamu follow & login di browser)

1

Tempel link story Instagram

Login ke Instagram di PC, buka story-nya, lalu copy URL-nya.

2

Dapatkan User ID dulu

Story butuh numeric User ID. Buka link ini di tab baru (pastikan sudah login IG), lalu cari "id":"..." di halamannya.

2b

Tempel User ID → dapat link GraphQL

Copy link ini, buka di tab baru.

3

Tempel isi halaman JSON

Di tab GraphQL tadi: Ctrl+U (view source) → Ctrl+A → Ctrl+C, lalu paste di sini.
